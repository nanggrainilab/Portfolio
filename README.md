# Novita Anggraini Portfolio (Next.js App Router, TypeScript, Tailwind)
```
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_CONTACT_EMAIL, NEXT_PUBLIC_GITHUB_URL, NEXT_PUBLIC_SITE_URL
npm run dev                  # http://localhost:3000
npm run build && npm start
```
Deploy: push to GitHub and import into Vercel (set the three env vars), or any Node host.
Content lives in `lib/projects.ts` (single source for cards and case studies).
Items to confirm before launch: email, GitHub URL, retail currency, metric definitions (see case study notes), 25% error-reduction method, SMOTE-in-fold check, official degree title.
